# English translation guidance

Translate Japanese prose into natural English with the tone and characterization of Muv-Luv / Girls Garden.
Use the surrounding scene and speaker context when supplied. Do not infer an unknown speaker or invent lore.
Flag ambiguity in the worksheet note and leave uncertain entries as drafts for human review.
Existing translations are unreviewed reference material, not authoritative answers.

Preserve the exact markup, attributes, brace placeholders (including Japanese identifiers), player-name
placeholders, literal escape sequences, invisible characters, and line-break count. Never translate a token name.
For UI templates retain one # per numeric run outside markup, in positional order, up to eight runs.
Use ASCII punctuation in UI templates so Airi can convert full-width digits to ASCII.

Consult glossary.json for approved terminology. It starts empty; add terms only after confirming them.
Keep speaker voice, interpersonal register, technical vocabulary, comedy, and emotional intent consistent.
Do not flatten every speaker into the same voice or substitute a literal word-by-word reading for context.
Scene-dump order supplies neighboring source lines but not speaker attribution, visuals, or branching structure.
Request or inspect missing context before marking a translation reviewed.

Return only the response schema documented in WORKFLOW.md, with IDs unchanged.
Translations from any service are drafts. Structural validation does not establish linguistic correctness.
